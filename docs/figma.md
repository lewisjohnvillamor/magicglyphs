# Figma

The Magic Glyphs plugin puts icons straight into your designs.

- **Search** every icon by name or tag.
- **Insert as a vector** in outline, solid or duotone, in any colour and size. It lands in the selected frame, ready to edit.
- **Insert as an animated GIF**, which plays in prototypes and presentations, so stakeholders see the motion.
- **Unlock the full library** with the licence key from your Gumroad receipt (the 120 free icons work without one).

Works in Figma Design, FigJam and Figma Slides.

Install it from the Figma Community (search for *Magic Glyphs*). Until it is listed there, a team can import it in the Figma desktop app: **Plugins → Development → Import plugin from manifest**, and choose `manifest.json` from the plugin folder we send you on request (support@magicglyphs.com).
